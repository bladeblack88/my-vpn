# Android client

Kotlin + Jetpack Compose Android app using the official WireGuard tunnel library.

## Build

- Android Studio stable
- JDK 17
- Android SDK 35

Open this directory as a project and run `assembleDebug`, or use the repository GitHub Actions workflow.

## Import

Import the client profile generated by `server/setup-wireguard.sh`. The profile contains a private key: keep it confidential.

The first connection triggers Android's system VPN permission dialog. Android allows only one active VPN service per user/profile.

This is an MVP. It does not yet implement persistent config encryption, a foreground connection status UI, kill-switch / always-on setup, multi-server selection, or server provisioning from the app.
